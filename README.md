# 🌸 Animated Flowers with Ambient Soundscape

An enchanting interactive animated flower garden built with pure CSS3 and JavaScript, accompanied by a soothing procedural Web Audio ambient soundscape.

Based on [Animated-Flower](https://github.com/Dev-tanay/Animated-Flower) by Tanay Das.

## ✨ Features

- **Blooming Flower Animation**: Intricately crafted CSS keyframe animations for glowing petals, stamens, leaves, and waving grass stalks.
- **Ambient Soundscape**: Real-time generative audio powered by Web Audio API — featuring gentle harmonic drones, calm night breezes, and delicate crystalline wind chimes.
- **Interactive Experience**: Click/tap anywhere on the canvas to trigger sparkling harmonic chime notes.
- **Sound Toggle**: Elegant glassmorphic floating control to mute/unmute audio seamlessly.
- **Pure Web Technologies**: 100% vanilla HTML5, CSS3, and JavaScript — zero external dependencies or heavy assets.
